# Banco de fotos do Instagram

Coloque aqui a foto de capa de cada post com o nome da data de publicacao: AAAA-MM-DD.jpg (ex.: 2026-10-19.jpg).
Use fotos reais da equipe/visitas (com autorizacao), Pexels/Unsplash (licenca de uso comercial) ou imagens geradas por IA.
Formato vertical (4:5) de preferencia, minimo 1080 px de largura.
